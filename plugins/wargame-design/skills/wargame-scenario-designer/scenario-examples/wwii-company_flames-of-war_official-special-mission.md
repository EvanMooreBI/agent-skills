# WWII company: Flames of War special mission format

**Rules system:** Flames of War, and other Battlefront systems that share its format
**Scale:** Company (teams on bases)
**Presentation:** The publisher's special-mission layout from supplement books

This file describes the publisher's layout in original words. It contains no mission text, OOBs, or rules. For a real mission, use your own copy of the supplement. For maps, use the `wargame-scenario-map-making` skill.

## Document structure

1. One or two paragraphs of historical narrative.
2. Orders for each side in italic second person.
3. A full-page deployment map with measurements in inches and centimeters.
4. An OOB for each side with the rules' ratings.
5. Numbered setup steps.
6. How the battle begins.
7. How the game ends.
8. How the winner is decided.

## How special missions differ from standard missions

Standard missions are generic templates with no historical context. Special missions:

- name a historical action and real units;
- give fixed OOBs instead of player-built forces;
- often use their own victory conditions;
- name supplement special rules without reproducing them.

## OOB format

The same two-column layout as historical scenarios: the historical designation on the left and the game unit on the right. The formation header carries the rating. Support units and reserves are listed separately and marked.

## Victory conditions

Special missions often score victory points per turn or for specific events, instead of plain objective holding. Write them as three short blocks:

```
ENDING THE GAME
[turn limit, or an end trigger]

DECIDING WHO WON
[each side's VP sources]
[tie-breaker]
```

Other options: bonus points for destroying key units, a penalty when a side's own losses pass a threshold, or points for terrain beyond the standard objectives.

## Structural lessons

- Use this format for a historically grounded game that needs fixed OOBs.
- Refer to the rules' special rules by name. Never rewrite them.
- Scenario-specific setup steps replace the generic deployment instructions.
- Points scored each turn create more movement than a single objective check.
