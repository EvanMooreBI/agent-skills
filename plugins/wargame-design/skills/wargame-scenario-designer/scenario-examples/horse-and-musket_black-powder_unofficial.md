# Horse and musket: Black Powder style scenario format

**Rules system:** Black Powder, Hail Caesar, and similar stat-line games
**Scale:** Grand tactical (brigades of regiments, with stat-line tables)
**Presentation:** A rulebook-style scenario with narrative, terrain rules, and stat tables

This file describes a common layout in original words. It contains no scenario text or stat values from a published source. For maps, use the `wargame-scenario-map-making` skill.

## Document structure

Usually four pages:

1. Historical narrative with a deployment map, often illustrated with photos of painted miniatures.
2. Terrain rules and a discussion of deployment.
3. The first army's OOB as stat tables by brigade.
4. The second army's OOB as stat tables by brigade.

## Narrative

Prose that sets up the strategic context, each commander's situation and plan, and the key tactical problem, such as a flanking attack against a fixed defense.

## OOB as stat tables

Each brigade gets a heading with its commander's command rating and a table with one row per unit. Use the column names from your rules. An illustrative table with invented values:

```
BRIGADE COMMANDER [NAME] (COMMAND RATING [n])

| Type      | Armament         | Melee | Shooting | Morale | Stamina | Special |
|-----------|------------------|-------|----------|--------|---------|---------|
| Infantry  | Rifled Musket    |   n   |    n     |   n    |    n    |   ...   |
| Artillery | [gun type]       |   n   |    n     |   n    |    n    |   ...   |
```

## Terrain rules

Give each terrain type its own paragraph covering both its appearance and its game effect, such as a visibility limit, a shooting modifier, or the cost of crossing water. Never describe terrain only by its look.

## Deployment

This format often describes deployment as a narrative of each player's choices rather than fixed zones. Flanking forces get explicit arrival rules.

## Structural lessons

- The armament column uses general weapon types, such as rifled musket, smoothbore musket, or a gun class.
- Terrain needs a stated game effect, not only a description.
- Deployment narrative can capture player reasoning as well as zone limits.
- Decisions made before the game, such as where to send a flanking force, add generalship.
- Command games need a command rating for each brigade leader.
