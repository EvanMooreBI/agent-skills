# WWII battalion: Battlefront WWII style scenario pack

**Rules system:** Battlefront WWII and similar battalion-level games
**Scale:** Battalion battlegroup
**Presentation:** A multi-page scenario pack with separate briefings for each side

This file describes a common layout in original words. It contains no scenario text, OOB data, or equipment codes from a published source. For maps, use the `wargame-scenario-map-making` skill.

## Document structure

Eight or more pages:

1. Player briefing for side A.
2. Force OOB for side A, as a tree with NATO symbols.
3. Deployment, notes, and special rules for side A.
4. Player briefing for side B.
5. Force OOB for side B.
6. Deployment and reinforcements for side B.
7. Map and terrain, with a legend.
8. Game notes, victory conditions, and an appendix of special rules.

## Player briefing

The briefing is written in the first person, from the commander's point of view. It covers:

- the place of the action within the wider operation;
- the commander's situation;
- intelligence on the enemy, which can be partly wrong;
- the commander's plan.

It ends on a vivid moment and gives the mission as one bullet.

## OOB as a tree

A hierarchy with NATO symbols: headquarters element, maneuver elements, and support. Each entry is `x[quantity] [type] ([notes]) [equipment code]`, using the rules' own equipment codes. An illustrative fragment with invented content:

```
BATTLEGROUP [quality]
  HEADQUARTERS
    x1 Commander [code]
  MANEUVER
    'A' Company [quality]
      x9 Infantry [code]
```

## Deployment

- Named lines on the map set the deployment limits.
- Each side's rules say which side of a line it deploys on, whether units start on or off the table, and any entry limits.
- Reinforcements arrive by a turn-by-turn table.
- Hidden-unit rules apply to each side.

## Map and terrain

A color map with a legend covering elevation levels, terrain types, built-up sectors with their heights, defensive works, named locations, and grid references.

## Victory conditions

A tiered table, such as total, major, and minor victory, with a condition for each side at each level.

## Structural lessons

- First-person briefings build investment and convey information that only one side has.
- A symbol tree makes command relationships visible.
- Equipment codes identify each element exactly.
- Fortifications need placement rules.
- Off-board artillery needs ammunition and availability limits.
- Footnotes on OOB entries can carry deployment conditions.
