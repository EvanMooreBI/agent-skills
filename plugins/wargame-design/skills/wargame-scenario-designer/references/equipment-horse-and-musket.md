# Horse & Musket Equipment Reference

## Skirmish Scale: Individual Weapons

- Smoothbore Musket (e.g., Brown Bess, Charleville M1777)
- Rifled Musket (e.g., Springfield M1861, Enfield P1853)
- Breech-loading Rifle (e.g., Sharps, Dreyse Needle Gun)
- Cavalry Carbine, Sabre, Lance, Pistol

## Artillery

Name the gun type: "6-pdr Smoothbore", "12-pdr Napoleon", "3-inch Ordnance Rifle", "12-pdr Howitzer", "Whitworth Rifle"

## Grand Tactical Scale: Stat-Table Conventions

At grand tactical scale (regiment/brigade level), OOBs use stat tables. The armament column uses aggregate weapon descriptions. Follow the convention from Black Powder / Hail Caesar:

```
| Unit | Type | Armament | Hand-to-Hand | Shooting | Morale | Stamina | Special |
```

**Armament descriptors at this scale:**
- Smoothbore Musket, Rifled Musket, Breech-loading Rifle, Magazine Rifle
- Sabre, Lance, Pistol, Rifled Carbine, Shotgun/Revolver
- 6-pdr Smoothbore, 12-pdr Howitzer, Rifled Artillery

## Regimental Scale: Regimental Fire and Fury Conventions

At regimental scale, each unit label represents an infantry regiment, cavalry squadron/regiment, or artillery battery/section. The **Regimental Fire and Fury (RFF)** label format is the gold standard for this scale. Every label encodes:

1. **Parent formation** in parentheses: `(Pattison)`, `(Little)`, `(Greer)`
2. **Unit designation**: `8 IN` (8th Indiana), `3 LA` (3rd Louisiana), `2 MO Inf` (2nd Missouri Infantry)
3. **Quality rating (3-letter code)**
4. **Weapon type (2-letter code)**

### Quality Ratings (RFF)

| Code | Rating |
|------|--------|
| **Crack** | Crack (elite units; rare) |
| **Vet** | Veteran |
| **Trn** | Trained |
| **Grn** | Green |

**Leader Ratings:**
- **Gallant** — Aggressive, inspiring commander
- **Able** — Competent, steady commander
- **Poor** — Hesitant or incompetent commander
- **Brave Colonel** — Exceptionally aggressive regimental commander

### Musketry Weapon Codes (RFF)

| Code | Weapon | Typical Examples |
|------|--------|-----------------|
| **RM** | Rifled Musket | Springfield M1861, Enfield P1853 |
| **SM** | Smoothbore Musket | Springfield M1842, Brown Bess |
| **IR** | Inferior Rifle | Mississippi Rifle, Hall Rifle, altered smoothbores |
| **RC** | Rifle & Carbine | Sharps Carbine, Burnside Carbine |
| **BLC** | Breechloader Carbine | Sharps Carbine (breech-loading), Smith Carbine |
| **BLR** | Breechloader Rifle | Sharps Rifle (full-length breech-loader) |
| **RPC** | Repeater Carbine | Spencer Carbine, Henry Carbine |
| **RPR** | Repeater Rifle | Spencer Rifle, Henry Rifle |
| **SH** | Shotgun & Hunting Rifle | Mixed civilian weapons (typical early-war Confederate) |

### Cannonade Weapon Codes (RFF — Artillery)

Each battery is typically split into sections (Left, Center, Right). Each section label carries a gun type code.

| Code | Gun Type | Typical Examples |
|------|----------|-----------------|
| **LS** | Light Smoothbore | 6-pdr gun |
| **LH** | Light Howitzer | 12-pdr Napoleon (Model 1857) — most common ACW field piece |
| **LR** | Light Rifle | 3-inch Ordnance Rifle, 10-pdr Parrott |
| **HS** | Heavy Smoothbore | 12-pdr gun, 24-pdr howitzer |
| **HR** | Heavy Rifle | 20-pdr Parrott, 4.5-inch Siege Rifle |
| **HH** | Heavy Howitzer | 24-pdr field howitzer, 8-inch howitzer |
| **MH** | Mountain Howitzer | 12-pdr mountain howitzer |

**Section size prefixes:**

| Prefix | Meaning |
|--------|---------|
| **L Sec/** | Left Section (standard 2-gun section) |
| **C Sec/** | Center Section |
| **R Sec/** | Right Section |
| **Sec/** | Single section (when battery has only one) |
| **Half-** | Half-section (1 gun instead of 2) |
| **Hrs** | Horse Artillery |

### RFF Label Format Example

```
(Pattison)
8 IN
Trn 11/10/8 RM

= 8th Indiana Infantry, Trained, armed with Rifled Muskets
  under Pattison's Brigade
  (strength figures are system-specific stand counts)
```

### RFF Unit Designation Conventions

- **Infantry regiments**: `8 IN` (8th Indiana), `3 LA` (3rd Louisiana), `44 IL` (44th Illinois)
- **Infantry battalions**: `Det/ 3 MO` (Detachment, 3rd Missouri), `Hughes MO Inf` (Hughes' Missouri Infantry Battalion)
- **Cavalry regiments**: `3 IA Cav` (3rd Iowa Cavalry), `9 TX Cav` (9th Texas Cavalry)
- **Mounted Rifles**: `1 AR Mtd Rifles` (1st Arkansas Mounted Rifles), `2 AR Mtd Rifles`
- **Dismounted cavalry**: add `Dismtd` to the label
- **Artillery**: `L Sec/ 1 IA` (Left Section, 1st Iowa Battery), `R Sec/ AR Btry` (Right Section, Arkansas Battery)
- **Named batteries**: Use commander's name: `Wade`, `Good`, `Bledsoe`, `Klauss`
- **Special units**: `2 Cherokee Mtd Rifles` (2nd Cherokee Mounted Rifles)
