# Modern (Post-WWII) Equipment Reference

**Important:** The weapon and vehicle lists below show correct naming conventions, not TO&E compositions. Before writing any OOB, research the actual Table of Organization and Equipment for the specific nation, branch, and year via web search. A 1967 USMC rifle squad is organized very differently from a 1967 US Army rifle squad, and both differ from a 2003 US Army rifle squad.

## Skirmish Scale: Individual Weapons

**Rifles:** M16A4, AK-74M, L85A2, FAMAS F1, G36
**Carbines:** M4A1, AKS-74U
**LMGs:** M249 SAW, RPK-74, L86A2 LSW
**GPMGs:** M240B, PKM, L7A2 GPMG, MG3
**DMR:** M14 EBR, SVD Dragunov, HK417
**Sniper:** M24 SWS, L96A1, Barrett M82A1
**AT Weapons:** AT-4, RPG-7, Javelin, Carl Gustaf M3, NLAW, TOW
**Grenade Launchers:** M203, GP-25, Mk 19 (vehicle-mounted)
**Pistols:** M9 Beretta, Makarov PM, SIG P226

## Platoon Scale: Squad Composition Examples

List each squad's composition with specific weapon types. Do NOT use FOW-style team type labels at platoon scale.

**US Army Rifle Squad (2003 Iraq, illustrative format — verify TO&E):**
```
Squad Leader: M4A1
Fire Team Alpha:
  Team Leader: M4A1 + M203
  Automatic Rifleman: M249 SAW
  Grenadier: M4A1 + M203
  Rifleman: M4A1
Fire Team Bravo:
  Team Leader: M4A1 + M203
  Automatic Rifleman: M249 SAW
  Rifleman: M4A1
  Rifleman (AT): M4A1 + AT-4
```

**Soviet Motor Rifle Squad (1980s, illustrative format — verify TO&E):**
```
Squad Leader: AKS-74
Machine Gunner: RPK-74
```

## Company/Battalion Scale: Team Types

At company scale and above, use team type labels per base/stand:

| Team Type | Typical Equipment |
|-----------|------------------|
| Rifle team | Standard infantry rifles |
| Rifle/MG team | Rifles + squad LMG |
| MG team | GPMG or MMG |
| Anti-tank team | RPG, Javelin, TOW, Carl Gustaf, NLAW, Milan, AT-4 |
| Mortar team | 60mm light mortar, 81mm medium mortar, 120mm heavy mortar |
| Sniper team | DMR or sniper rifle + spotter |
| Forward Observer | Radio + binoculars (calls off-board fire) |
| ATGM team | TOW, Milan, Kornet, Javelin (vehicle or dismounted) |
| HMG team | M2 .50 cal, DShK, NSV |
| AGL team | Mk 19, AGS-17 |
| SAM team | Stinger, Igla, Starstreak |
| Engineer/Pioneer team | Assault rifles + demo charges, mine detectors |
| Command team | Officer + RTO |

## Vehicles by Nation

Always use the specific variant designation.

### United States
**Tanks:** M1A2 Abrams SEP v3, M1A1 Abrams, M60A3 Patton
**IFVs:** M2A3 Bradley, M3A3 Bradley (cavalry)
**APCs:** M113A3, Stryker ICV (M1126)
**Utility:** HMMWV (M1114 up-armored), MRAP (MaxxPro, Cougar), M-ATV
**Artillery:** M109A6 Paladin (155mm SP), M119A3 (105mm towed), M777A2 (155mm towed)

### Russia / Soviet Union
**Tanks:** T-72B3, T-80BVM, T-90M, T-55AM (Cold War), T-62M (Cold War)
**IFVs:** BMP-2, BMP-3, BMD-4M (airborne)
**APCs:** BTR-80, BTR-82A, MT-LB
**Utility:** UAZ-469, Tigr-M
**Artillery:** 2S19 Msta (152mm SP), D-30 (122mm towed), BM-21 Grad (122mm MRL)

### United Kingdom
**Tanks:** Challenger 2 (TES), Chieftain Mk.11 (Cold War)
**IFVs:** Warrior IFV (FV510)
**APCs:** FV432 Bulldog, Mastiff PPV
**Utility:** Land Rover WMIK, Jackal MWMIK
**Artillery:** AS-90 (155mm SP), L118 Light Gun (105mm towed)

### Germany
**Tanks:** Leopard 2A7, Leopard 2A4 (Cold War), Leopard 1A5 (Cold War)
**IFVs:** Marder 1A3, Puma IFV
**APCs:** Fuchs (TPz 1), Boxer IFV
**Artillery:** PzH 2000 (155mm SP)

## Notes

Modern and Cold War scenarios typically use the general five-tier quality ratings (Green / Trained / Experienced / Veteran / Elite) unless designed for Team Yankee, which uses the Flames of War Skill/Motivation system (see core `oob-equipment-conventions.md`).
